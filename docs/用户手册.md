# 用户手册

## 访问入口

- 系统地址：`http://localhost:3665`

## 登录

- 默认账号：`admin`
- 默认密码：`123456`

如需确认初始化是否包含账号数据，可在 SQL Server 中查询：

```sql
SELECT username, realname, status FROM sys_user;
```

## 常见功能路径（示例）

不同版本菜单结构可能略有差异，以下为常见模块的使用路径参考：

- **系统管理**：用户/角色/菜单/组织机构/数据字典
- **在线开发**：在线表单、在线报表、代码生成
- **流程与审批**：流程定义、待办、已办

## 基础操作

### 1) 修改密码

一般在右上角用户菜单中进入个人设置或安全设置，完成密码修改。

### 2) 文件上传

系统上传文件默认映射到宿主机目录：`jeecg-boot/data/uploads`。

### 3) 常见问题排查

- 页面无法访问：确认容器是否启动，端口 `3665` 是否被占用。
- 登录报错/空白：查看 `jeecg-backend` 日志是否存在数据库连接失败。
- 初始化失败：查看 `jeecg-sqlserver-init` 日志并根据错误信息重跑初始化。


## 设备档案

### 功能入口

顶部菜单：**设备管理 → 设备档案**。

### 设备维护

- **新增**：点击「新增」，填写设备编号（唯一）、设备名称、型号、厂商、位置、启用日期等信息。
- **编辑/删除**：列表行支持编辑与删除；删除设备时会在同一事务内清除其全部附件记录，不会产生孤儿附件。
- **批量删除**：勾选多台设备后，通过「批量操作」删除（同样会级联清理附件）。

### 附件区（设备详情）

点击列表行的「详情」打开设备详情抽屉，底部即**附件区**：

1. 通过顶部分类页签选择要上传的附件类别：**设备照片 / 说明书 / 维保合同 / 其他**（「全部」下上传默认归为其他）。
2. 点击「上传…」按钮选择一个或多个文件，单个文件不超过 **50MB**。
3. 附件列表展示：**文件名（可点击下载）、分类、大小、上传人、上传时间**。
4. 删除附件：点击行内「删除」会弹出二次确认，确认后才会删除记录及本地物理文件（远端 OSS/MinIO 仅清理记录）。
