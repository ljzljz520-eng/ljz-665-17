# 用户手册

## 访问入口

- 系统地址：`http://localhost:3665`

## 登录

- 默认账号：`admin`
- 默认密码：`123456`

如需确认初始化是否包含账号数据，可在 SQL Server 中查询：

```sql
SELECT username, realname, status FROM sys_user;
```

## 常见功能路径（示例）

不同版本菜单结构可能略有差异，以下为常见模块的使用路径参考：

- **系统管理**：用户/角色/菜单/组织机构/数据字典
- **在线开发**：在线表单、在线报表、代码生成
- **流程与审批**：流程定义、待办、已办

## 基础操作

### 1) 修改密码

一般在右上角用户菜单中进入个人设置或安全设置，完成密码修改。

### 2) 文件上传

系统上传文件默认映射到宿主机目录：`jeecg-boot/data/uploads`。

### 3) 常见问题排查

- 页面无法访问：确认容器是否启动，端口 `3665` 是否被占用。
- 登录报错/空白：查看 `jeecg-backend` 日志是否存在数据库连接失败。
- 初始化失败：查看 `jeecg-sqlserver-init` 日志并根据错误信息重跑初始化。


## 设备管理（设备档案与附件）

部署增量脚本后（见 `db/device/README.md`），左侧菜单出现 **设备管理 → 设备档案**。

### 设备档案

- 支持按设备编号、设备名称、生产厂家查询；
- 可新增、编辑、删除（单条/批量）设备档案。删除为高危操作，前端会二次确认，
  确认后设备与其全部附件在后端同一事务内级联删除，不会残留孤儿附件记录。

### 附件区（设备详情）

在列表点击某台设备的 **详情**，抽屉下半部分即“附件区”：

1. 先选择附件类型：**设备照片 / 说明书 / 维保合同 / 其他**；
2. 点击 **上传附件**，可多选；支持图片（jpg/png 等）、PDF、Office 文档、压缩包，
   单个文件不超过 50MB；
3. 列表展示：类型标签、**文件名**、大小、**上传人**（真实姓名，缺失时显示账号）、
   **上传时间**；
4. 点击文件名或“下载”可下载；
5. 点击“删除”会弹出 **确认删除该附件？** 的二次确认，确认后同时删除数据库记录与
   本地物理文件。

> 注：附件必须挂在已保存的设备上，新增设备请先保存档案，再进入详情上传。
